Built a production-grade AI system for neurosurgery training at one of India's premier medical institutions.

- Architected a **multimodal RAG pipeline** using CLIP embeddings + ChromaDB, enabling semantic retrieval across surgical video frames and clinical text
- Built an async LLM inference layer integrating Groq API and Llama models via FastAPI — reduced query latency by **40%** under concurrent load
- Engineered **real-time video processing at 30 FPS** (OpenCV + Mediapipe) for live surgical step recognition and contextual Q&A

- System validated in live training sessions with neurosurgery residents
